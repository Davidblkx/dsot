## Summary

In this session, we ported the Inbox view from the desktop application (`src/app/desktop`) to the mobile application (`src/app/mobile`). 

## Changes Made

- Copied the `inbox` module (including the components `item.rs`, `filter.rs`, and the `add_form` sub-module) into `src/app/mobile/src/views/inbox`.
- Copied the desktop's `inbox.css` and `view.css` into `src/app/mobile/assets/styles/view/`.
- Modified `src/app/mobile/src/views/inbox/add_form/mod.rs` to replace the `Dialog` modal with an inline form (`div`), making it touch-friendly and compliant with mobile UI best practices.
- Registered the new `InboxView` in `src/app/mobile/src/routes.rs`.
- Provided the necessary state to the application in `src/app/mobile/src/main.rs` (`use_provide_add_inbox_state()`) and included `view.css` in the `UI_STYLES`.
- Added the `rfd` crate dependency to `src/app/mobile/Cargo.toml` so that the form inputs function identically.
- Recreated the `widgets/views` module on mobile, duplicating the `Header` and `View` wrappers to remain consistent with desktop's component boundaries.
